ABOUT Project LPT

Project LPTについて

Project LPTは、ヴィジュアル系ロックバンドLaputaとakiのソロ活動について調べ、集めた情報を整理し、記録していく個人プロジェクトである（非公式）。

Laputaの音楽には、独特な音楽性と世界観がある。
長い時間を経ても、その作品を聴いたり、当時の資料を読み返したりすることで、20年以上たった今でも新しい発見がある。

このサイトでは、Laputaの作品や活動について改めて調べることで、今だからこそ分かること、改めて面白いと思えることを見つけ、Laputaの世界の素晴らしさを再認識することを目指している。

そして、そこで見つけた面白さを、自分だけのものにせず、できるだけ多くの人に伝えていきたいと考えている。

このサイトで扱うもの

Project LPTでは、Laputaとakiの作品や活動について、さまざまな資料を集めている。

歌詞や楽曲データだけではなく、当時の雑誌や書籍、インタビュー記事、Web上の記事、映像・動画なども対象としている。

集めた資料から、気になったことを調べたり、データとして整理したり、Pythonを使って集計・可視化したりしながら、面白いと思った結果をこのサイトに掲載していく。

Laputaやakiに関する資料の多くは、1990年代以降に発表されたものである。特にLaputaが活動していた90～00年代当時はSNSもない時代であったため、Laputaに関する情報がそもそもどこにあるのかを、今となっては探すことも難しい。また、数十年前の雑誌など、現在では入手しにくいものや、プレミア価格になっている資料も多い。そのため、資料は古書店やフリマサイト、必要に応じて図書館も利用しながら少しずつ集めている。

現在はLaputaを中心に分析を行っているが、akiのソロ活動についても資料や楽曲データを集めており、今後分析していく予定である。

Webサイトのデザインについて

Project LPTのWebサイトは、1990年代後半から2000年代初頭のWebサイトをイメージして、あえて当時風のデザインにしている。

Laputaが活動していた時代の個人サイトや音楽サイトに見られた、黒を基調とした画面、フレーム構成、テキスト中心のレイアウト、バナーやリンクを使ったナビゲーションなどを取り入れている。

これは単に古いWebサイトを再現することが目的ではない。

Laputaが活動していた時代に実際に存在していたWebの雰囲気を、現在のWeb上でもう一度作ってみたいと考えたためである。

一方で、サイトの中で扱っているデータの整理や分析には、現在の技術を使用している。

当時のWebサイトの雰囲気と、現在のデータ分析を同じ場所に置くこと。
それもProject LPTのデザインコンセプトの一つである。
